# Coffeewiz – Web-App

Kaffee-Rezepte mit Vergleichsanzeige („Fürs nächste Mal anpassen“) und Wizard.
Läuft komplett im Browser, die Daten bleiben auf deinem Handy.

**Öffnen:** https://knippca-sketch.github.io/coffeewiz/

**Installieren:**
- Android (Chrome): Menü ⋮ → „App installieren“ bzw. „Zum Startbildschirm hinzufügen“
- iPhone (Safari): Teilen-Symbol → „Zum Home-Bildschirm“

Deine Kaffees werden nur im Browser gespeichert. Sichere sie regelmäßig über
Einstellungen › Sicherung, sonst sind sie weg, wenn das Handy verloren geht
oder die Browserdaten gelöscht werden.

Dieses Repository enthält nur die fertig gebauten Dateien und wird automatisch
aktualisiert. Lizenz und Hinweise zu fremden Bestandteilen: [LICENSE.md](LICENSE.md).
